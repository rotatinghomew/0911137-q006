# 资料口径

薪酬按年、人民币计，fte 为工时比例。compensation 的 bonus=null 是未申报，0 是确认无奖金；equity_units 需乘对应年度 valuations.price。bands 的 lower/upper 是全职固定薪资薪带，不约束奖金。group 是合成分组码，不含真实敏感身份。任何模型差异都不是因果歧视结论。

## 现有资料

- `employees`：90 条本地记录。
- `compensation`：180 条本地记录。
- `bands`：6 条本地记录。
- `valuations`：2 条本地记录。

所有日期、月份、周或小时均用各表中的整数业务时标，页面的分析时点使用同一单位。资料中的 known 字段表示该行信息何时对分析可见，不是数据载入时间。字段名按原始业务接口保留。

这些记录是项目随附的虚构业务数据，不包含真实员工、客户、交易或设备。`fixtures/data.json` 的表结构可通过资料查阅页面检查；服务不从外网补数。

## 差异分析口径

- 比较维度：`group`（合成分组）或 `region`（地区）。参照群体由 `baseline` 指定，未指定时取当前范围内的第一个取值。
- 薪酬口径：`fixed_fulltime`（固定薪资除以 fte）、`bonus_declared`（仅已申报奖金）、`equity`（当期统一估值）、`total_complete`（实际支付的固定+已申报奖金+股权）。
- 匹配维度：岗位层级、工时、任职时间带、地区。主口径为岗位层级 + 工时 + 地区；任职时间带作为额外可审查口径，带宽由 `tenure_width` 指定（默认 10 年）。
- 共同支持：只有同时包含被比较两个群体的单元格才进入可比样本。若一个共同单元格都没有，结果标记为不可比，`within_difference` 与 `composition_difference` 为 `null`，不产生“已调整差距”。
- 任职时间带还要求两组在该单元格内实际任职时间区间有交集；仅有相同时间带标签不足以构成可比。
- 差异符号为“参照群体减对比群体”。原始差异 = 可比样本内原始差异（matched_raw_difference）+ 未进入共可比单元格的部分（unmatched_difference）；可比样本内原始差异 = 岗位内差异（within_difference）+ 构成差异（composition_difference）。构成部分说明人员构成带来的差异，岗位内部分说明在可比岗位内仍存在的差异。
- 权重为两组合并样本量加权；覆盖人数与排除人数逐项返回，不把未覆盖人员强行重分配。
- 敏感度同时报告：不同匹配字段组合、全部工时与仅全职样本、任职时间带宽、回归模型设定。回归只在主口径共同支持样本内拟合；与设计共线的控制项（例如按岗位固定的地区或任职时间）会被丢弃并列出。各口径共同支持样本不同，范围只表示敏感性，不是置信区间。

## 未申报、零值与股权估值

- 奖金 `null` 与 `0` 分开：未申报记录从奖金与完整总额的样本中剔除，不按零计入；`0` 是确认无奖金，计入均值。
- 股权统一使用所选分析年度的 `valuations.price`；该年有薪酬记录但缺少估值时分析报错，不混用其他年度单价。

## 调薪试算口径

- 规则：`uniform_percent`（统一比例）或 `band_floor`（只补齐低于薪带下限者）。
- 成本按全职金额乘 fte 计为名义固定薪资成本，不含奖金与股权。
- 硬约束：员工薪资下限（`floor`）与既有薪带上下限（`honor_bands`）。方案执行后仍低于下限、低于薪带下限、缺少薪带、薪带上限截断、预算不足等情形均逐条保留在 `unmet` 与 `adjustments` 中。
- 分项成本满足恒等式：总额 = 政策调薪 + 下限补齐 + 薪带补齐 - 薪带上限截断。
- 预算内适配（`fit_budget`）只对统一比例规则生效；薪带补齐规则金额与比例无关，不接受该开关。适配后的执行比例单独返回，不把统计残差变成个人补薪指令。

## 分析版本与导出

当前分析从同一份文件一次读取所有表，并把原始字节的 SHA-256 与筛选条件一起返回。保存分析时重新基于指定条件计算，保存的是结果值及该次资料指纹，而不是指向未来可变数据的引用。已有版本只读；同名保存产生另一条版本。历史结果保留原有字段语义，不因最新源文件被替换而重算。

评审导出只基于已保存版本生成，不含员工级记录、`rows` 或个人试算明细。少于五人的分组不发布人数与成本；同一分项中只要存在小分组，其余分组成本一并抑制，避免用总数相减反推。差异估计若依赖少于五人的分组或单元格，整条差异数值也不发布。导出保留不可比原因、未满足约束和抑制说明。
